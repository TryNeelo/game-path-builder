# game-path-builder

**Build the Path**: a path-building game for kids aged 6–8, made for iPad and touch screens. The child drags road pieces onto a grid, turns them with a tap, and taps the star to send the owl along the road, collecting coins on the way.

**Play it:** https://tryneelo.github.io/game-path-builder/

- `index.html`: the whole game in one file (HTML, CSS and JavaScript). Music and sound effects are generated in code.
- `assets/`: character, bat, coin and star art.
- `DESIGN.md`: the game design, including the rules, the teaching sections, springs and the decisions behind them.

To run it locally, serve the folder with any static web server and open `index.html`.
